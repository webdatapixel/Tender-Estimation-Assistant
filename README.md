# Tender & Estimation Assistant

A browser-only MEP tender review prototype. It accepts tender files and pasted document text, then generates:

- Project summary
- Important dates
- MEP systems required
- Missing information and risks
- Suggested RFIs
- Estimation checklist
- Quotation draft structure

Open `index.html` in a browser to use it.

## Notes

This version runs locally in the browser. It can read text-based files such as `.txt`, `.csv`, and `.rtf`; for PDF, Word, Excel, drawings, and scanned images, paste extracted text into the Tender Notes field for deeper analysis.

The quotation amounts are placeholder allowances intended to structure the offer. Replace them with BOQ measurements, supplier quotes, and approved company rates before submission.
